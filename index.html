Introduction to HTML

Understand what HTML is, why it matters, and how it forms the backbone of every web page on the internet.

Theory

What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create and structure content on the web. It is not a programming language — it is a markup language that tells browsers how to organize text, images, links, and other elements into a structured document that users can see and interact with.

Every website you visit — from search engines to social networks to online stores — is built on an HTML foundation. HTML provides the skeleton; CSS adds the visual styling, and JavaScript provides interactivity. Together they form the three core pillars of front-end web development.

How HTML Works

When you open a web page, your browser downloads the HTML file from a server and parses it top-to-bottom. It builds a tree-like structure called the DOM (Document Object Model), which represents every element on the page. The browser then renders this tree visually on your screen.

  • The browser requests an HTML file from the web server
  • The server responds with raw HTML text
  • The browser parses the HTML and constructs the DOM tree
  • The browser then renders the page by painting pixels to the screen
  • CSS and JavaScript files referenced in the HTML are fetched and applied

The Basic HTML Document Structure

Every HTML document follows a standard structure. The <!DOCTYPE html> declaration tells the browser this is an HTML5 document. The <html> element is the root that contains everything. Inside it, <head> holds metadata (title, character set, linked stylesheets), and <body> holds all the visible content users see on the page.

Tip Always include the lang attribute on the <html> tag (e.g., lang="en"). This helps screen readers pronounce content correctly and improves SEO.

HTML Tags vs. Elements vs. Attributes

A tag is the code between angle brackets, like <p> or </p>. An element is the complete unit: the opening tag, content, and closing tag combined, e.g. <p>Hello</p>. An attribute provides extra information about an element and is written inside the opening tag, like <a href="https://example.com">.

  • Tag: The markup notation, e.g., <h1> (opening) and </h1> (closing)
  • Element: The opening tag + content + closing tag as a whole
  • Attribute: Key-value pairs inside the opening tag, e.g., class="title"
  • Self-closing tags: Elements like <img />, <br />, and <input /> have no closing tag
Note HTML is not case-sensitive, but the convention is to write all tags in lowercase. This keeps your code consistent and readable.

Code Examples

HTML Basic HTML Document
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>This is my first ever HTML web page.</p>
</body>
</html>
